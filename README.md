# Tuberculosis_Python

## Descripción
Proyecto escolar realizado con python en google colab, en donde se analizan datos de casos de tuberculosis en todo el mundo, agrupando los datos por región, grupo de edad, genero, y elaborando algunos gráficos para un mejor entendimiento.

## Proceso
Primero se obtuvieron las bases de datos que fueron proporcionadas, se cargaron en la plataforma google colab y se realizó una depuración de las mismas, reemplazando valores nulos, intercambiando columnas por filas, unificando bases de datos, creando variables, etc.

Despues se procedió a agrupar los datos de acuerdo al género, edad, casos, países, etc.

Finalmente, se crearon algunos gráficos que ayudan a comprender mejor el comportamiento de la enfermedad a lo largo del tiempo.

## Herramientas utilizadas
* Base de datos proporcionada.

* Google colab.
